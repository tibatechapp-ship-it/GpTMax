What GpTMax does

A Compose-native Android app: a code editor, a chat with local answers, and a bounded coding agent — all backed by an on-device GGUF engine.

On-device inference

Downloads GGUF models once, then runs them locally through a pinned llama.cpp build optimized for ARM64. No prompt ever leaves the phone unless you say so.

Bring-your-own-key bridge

Optionally connect your own API key (BigModel, DeepSeek, OpenRouter, or any OpenAI-compatible endpoint). The key is stored in app-private storage and used only for your requests.

Agent with guardrails

Plan → act → validate loop with a human approval gate on every write, a full-content rollback journal, command sandboxing, and honest PARTIAL/BLOCKED outcomes.

Scoped workspace

Works only inside the project folder you grant through Android's document picker. No broad storage permission, no background scanning.

Privacy by architecture

GpTMax has no accounts, no analytics, no ads, and no tracking SDKs. Nothing is collected by the developer. Data lives on your device:

  • Chats and agent runs stay in the app's local database
  • Settings and API keys stay in app-private storage (no cloud backup)
  • Network is used only when you download a model (from huggingface.co) or enable the optional cloud bridge
  • Uninstalling the app removes all locally stored data

  • الوصول للملفات عبر نطاق مجلد واحد تمنحه أنت بنفسك
  • حذف البيانات: إلغاء تثبيت التطبيق يحذف كل ما خُزّن محليًا
