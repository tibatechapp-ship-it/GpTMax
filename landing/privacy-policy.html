GpTMax Privacy Policy

Effective date: November 26, 2026 · Developer: tibatechapp-ship-it · Applies to the GpTMax Android app (all versions published on Google Play or elsewhere).

1. Summary

GpTMax is a local-first AI coding studio. The short version:

  • We (the developer) do not collect, receive, or store any of your data. There are no accounts, no analytics, no advertising, and no tracking SDKs in the app.
  • Your code, chats, agent runs, settings, and any API key you enter are stored only on your device, in app-private storage.
  • The app uses the network only for two user-initiated purposes: downloading AI model files from huggingface.co, and — if you explicitly enable and configure it — optional cloud inference through a provider of your choice using your own API key.
  • Uninstalling the app deletes everything stored locally.

2. Data stored on your device (never sent to us)

  • Chats and agent runs — kept in the app's local Room database (gptmax.db).
  • Settings, including your optional cloud-provider configuration and API key — kept in app-private DataStore storage.
  • Agent safety artifacts (rollback journal entries and resume snapshots) — kept in the app's private files directory so interrupted work can be resumed or rolled back.
  • Workspace files — your own project files, accessed only inside the single folder you grant through Android's document picker (Storage Access Framework). The app has no broad storage permission and does not scan files outside that scope.
  • Downloaded AI models — stored in the app's private storage; you can delete them at any time from the Models screen inside the app.

The app sets allowBackup="false", so none of this data is included in Android cloud backups.

3. When the app uses the network

3.1 Model downloads (optional, user-initiated)

When you tap a download in the Models screen, the app fetches the chosen GGUF model file directly from huggingface.co over HTTPS. The list of catalog models ships with the app; the download goes straight from the model host to your device. The developer does not proxy, log, or observe these downloads.

3.2 Optional cloud inference (bring-your-own-key)

By default GpTMax answers using the on-device engine. If you explicitly configure a cloud provider — BigModel (open.bigmodel.cn), DeepSeek (api.deepseek.com), OpenRouter (openrouter.ai), or a custom OpenAI-compatible endpoint you enter — the app will send your prompt text to that endpoint over HTTPS so the provider can generate a response. Additional facts:

  • The API key you supply is stored only in app-private storage on your device and is transmitted only to the endpoint you configured, as authentication for your own requests.
  • The app refuses non-HTTPS endpoints when an API key is configured.
  • What happens to your prompt text after it reaches the provider is governed by that provider's privacy policy, not ours. Choose providers you trust.
  • Cloud use is entirely optional and off unless you turn it on; the local engine works with no configuration.

4. Permissions

PermissionWhy
INTERNETThe only declared permission. Used for model downloads (huggingface.co) and, only if you enable it, the optional cloud bridge.

GpTMax does not request access to contacts, location, camera, microphone, phone state, or broad storage. File access is the narrow, user-granted document-picker scope described above.

5. What we do NOT do

  • We do not collect or receive your prompts, code, model list, or usage statistics.
  • We do not embed analytics, crash reporting, advertising, or attribution SDKs.
  • We do not sell, rent, or broker any data — there is no data flowing to us to sell.
  • We do not require an account, and there is no sign-in.

6. Data retention and deletion

All data described in section 2 lives on your device. Uninstalling GpTMax deletes all of it. Within the app you can delete downloaded models from the Models screen. Because we hold nothing server-side, there is nothing for us to delete on request.

7. Children's privacy

GpTMax is a developer tool and is not directed at children under 13. We do not knowingly collect any personal information from anyone — including children — because no data reaches us.

8. Security

  • App-private storage enforced by the Android sandbox; no data is written to shared storage.
  • Cloud backups disabled (allowBackup="false").
  • All network traffic uses HTTPS; keyed cloud endpoints are HTTPS-enforced by the app.
  • Commands the agent may run (optional, user-approved per command) execute in a restricted sandbox with a bare environment and hard output limits.

9. Changes to this policy

If the app's data practices change materially, we will update this page and change the effective date above before the updated version ships to Google Play.

10. Contact

Questions or requests about privacy: open an issue at github.com/tibatechapp-ship-it/GpTMax/issues. Support is community-based; see the repository's SUPPORT.md.

  • محادثاتك وأكوادك وإعداداتك وأي مفتاح API تدخله تُخزَّن على جهازك فقط في مساحة خاصة بالتطبيق.
  • يستخدم التطبيق الإنترنت لغرضَين يبدأهما أنت فقط: تنزيل ملفات نماذج GGUF من huggingface.co، وخدمة الاستدلال السحابي الاختيارية عبر مزوّد تختاره أنت بمفتاحك الخاص.
  • المفتاح يُرسل فقط إلى الجهة التي أعددتها بنفسك، ولا يُفعَّل الاتصال السحابي إلا بموافقتك الصريحة، والاستدلال المحلي يعمل بدونه.
