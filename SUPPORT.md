# Support

- **Bug reports:** use the Bug Report issue template.
- **Feature proposals:** use the Feature Request template after checking the roadmap.
- **Security issues:** follow [SECURITY.md](SECURITY.md); do not report them publicly.
- **Usage questions:** open a GitHub Discussion if Discussions are enabled, otherwise use an issue clearly marked as a question.

Please provide reproducible steps, relevant logs with secrets and personal data removed, device model, Android version, ABI, and backend details where applicable. Support is community-based; no response time or compatibility guarantee is implied.
