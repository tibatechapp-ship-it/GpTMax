# Security Policy

## Supported versions

Security fixes are currently considered for the latest default-branch code. Published release support will be documented when releases begin.

## Reporting a vulnerability

Please do **not** disclose suspected vulnerabilities in public issues, discussions, or pull requests.

Use GitHub's private vulnerability reporting / Security Advisories for this repository:
https://github.com/tibatechapp-ship-it/GpTMax/security/advisories/new

Include a concise description, impact, affected commit/version, reproduction steps, and a proposed mitigation if available. Avoid sending real user prompts, personal data, model files, or secrets.

The maintainers will triage reports in good faith, keep the reporter informed when possible, and coordinate disclosure after a fix or mitigation is available. Do not test against other users' devices or data.
